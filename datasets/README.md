# Dados de laboratório

[← Laboratórios](../labs/README.md)

Todos os registros locais foram criados sinteticamente para esta formação. Não representam incidentes, pessoas ou indicadores reais. Domínios `.example` e IPs de documentação não devem alimentar blocklists.

- `auth-events.csv`: autenticação fictícia, timestamps UTC, clientes A/B, IDs únicos. Os rótulos representam cenários didáticos, não ground truth de comprometimento.
- `source-fixture.json`: duplicata, edição e entrada inválida para avaliar ingestão.

Os dados sintéticos desta pasta são disponibilizados sob CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/ . Essa declaração se aplica apenas aos dados desta pasta, não altera direitos sobre referências externas ou sobre o restante do projeto.
