# Sistema visual

Identidade editorial original, centrada em investigação e rastreabilidade.

| Elemento | Valor | Uso |
|---|---|---|
| Fundo | `#080E1A` e `#101D31` | Banner |
| Menta | `#39D8C5` | CTI e pontos de evidência |
| Lavanda | `#A99BFF` | SOC e relações |
| Texto principal | `#F3F7FC` | Títulos |
| Texto secundário | `#B6C4D7` | Subtítulos |

SVG nativo, sem fontes remotas, scripts ou imagens externas. No Markdown, manter contraste nativo do GitHub; não depender de CSS customizado. Usar cabeçalhos curtos, tabelas para comparação e links de retorno nas páginas. Textos alternativos devem descrever a função da imagem. O desenho de rede é decorativo, não representa resultados de investigação.
